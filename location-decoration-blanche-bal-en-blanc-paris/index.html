Vos questions sur la location

Quels décors pour une soirée en blanc ?

Les nuages, les étoiles blanches (anciennes et fines), les sphères drapées, les marguerites et les drapés se combinent pour un plafond entièrement blanc.

Peut-on les éclairer en couleur ?

Oui : le blanc prend toutes les couleurs des projecteurs, c'est l'intérêt d'un décor blanc.

Peut-on ajouter des ballons blancs ?

Oui, on peut vous orienter vers des compositions de ballons ; indiquez-le dans votre demande.
